# tests-corpus — OOXML round-trip golden corpus

This directory holds `.docx` files used as golden inputs for round-trip fidelity tests.

## Categories (target taxonomy)

- `academic/` — Thesis chapters, journal articles, citation-heavy
- `legal/` — Bluebook citations, complex tables of authorities
- `multilingual/` — Spanish, Portuguese, German, French, Arabic, Chinese (RTL/CJK testing)
- `equations/` — Math-heavy with MathML / OMML
- `tables/` — Complex tables, merged cells, nested
- `tracked/` — Track-changes + comments
- `legacy/` — `.doc` (Word 97-2003) for compatibility tests

## Goals

- v0 milestone: 100 docs total, ≥95% byte-equivalent round-trip
- v1 milestone: 500 docs total, ≥99% byte-equivalent round-trip on simple categories

## How to add a doc

1. Add `.docx` to the appropriate category subdirectory.
2. Run `cargo test --release --test corpus_round_trip -- --ignored` to generate a snapshot.
3. Review the snapshot diff and `cargo insta accept` if the baseline is correct.
4. Commit both the `.docx` and the snapshot.

## What NOT to commit

- Files that contain real PII (use anonymized fixtures only).
- Files larger than 5 MB (compress or split).

## Validation Gate 4 starter set

Five fixtures committed for the first OOXML round-trip moat run. Each was generated by writing a
small source file (HTML / FODT) and converting via headless LibreOffice, so the output is real-world
LibreOffice-produced OOXML — full namespace declarations, BodyText / Heading1-4 styles, page setup,
the footnote machinery, etc.

| Fixture                            | Source format                          | OOXML markers                                            |
| ---------------------------------- | -------------------------------------- | -------------------------------------------------------- |
| `academic/simple-paragraph.docx`   | HTML, single `<p>`                     | one `w:p` with `BodyText` style                          |
| `academic/heading-hierarchy.docx`  | HTML with `<h1>`–`<h4>`, `<p>`, `<ul>` | `Heading1`–`Heading4` styles, `BodyText`, list paragraph |
| `multilingual/spanish-tildes.docx` | plain text                             | ñ á é í ó ú ü ç ¿ ¡ — full LATAM coverage                |
| `tables/simple-table.docx`         | HTML 3×3 `<table>`                     | `w:tbl` + `TableContents` style, surrounding paragraphs  |
| `footnotes/single-footnote.docx`   | flat ODT (`.fodt`) with `<text:note>`  | `w:footnoteReference` + footnotes part                   |

Regenerate (e.g. after a LibreOffice upgrade) with:

```
soffice --headless --norestore --nologo \
  --infilter='HTML (StarWriter)' \
  --convert-to docx --outdir tests-corpus/<category>/ <source>
```

(omit `--infilter` for `.txt` / `.fodt` sources). The original sources are not committed; they are
trivial enough to recreate from this table when needed.
